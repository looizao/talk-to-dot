## First public release

Talk to Zip opens ChatGPT and navigates to the Dot conversation named **zip** using Android Accessibility automation.

- Handles Tasks and other nested screens with **Navigate up / Navegar para cima**, then opens the sidebar and selects Zip.
- Brings ChatGPT's main activity forward when an old browser tab is above it.
- Restricts automation to ChatGPT and a 15-second window after shortcut launch.
- Includes source, setup instructions, CLI builds, and GitHub Actions builds and releases.

### Validation

Navigation was tested on a Motorola Edge 60 Pro running ChatGPT 1.2026.272. The exact **Tasks → Home → tap Talk to Zip → Message zip** flow passed twice, including with an ordinary chat underneath Tasks. The user also confirmed the installed fix worked.

The APK is signed with the same key as the local prototype, so it can update that installation. CI development APKs use a different key.

### Compatibility

This version requires a Dot named `zip` and the observed UI labels. Accessibility access is required. ChatGPT updates or translated labels may require a source update. There is no public Dot deep link or configurable Dot-name setting in this release. See the README for setup and customization.
