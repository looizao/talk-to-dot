# Talk to Dot v1.3.0

Choose the shortcut’s home-screen icon as well as its Dot name. The redesigned settings screen includes a live preview and six icon choices: **Frog**, **Cat**, **Fox**, **Bear**, **Owl**, and **Classic D**. The green frog is the default; **zip** remains the default Dot name.

- Original Dot-style character illustrations with rounded shapes, expressive eyes, shading, and bow ties. These are project artwork, not official OpenAI assets.
- **Save changes** saves both the exact Dot name and icon; **Save and open Dot** saves both and opens the conversation. Unsaved icon previews do not change the launcher.
- **Reset name to zip** restores only the default name, leaving the icon choice independent.
- The icon selection is saved locally and retained across settings reopening and signed updates. No new permissions or network access are added.
- Icon changes use Android launcher aliases, while the navigation activity and Accessibility service remain enabled. The original launcher identifier is retained for the default frog; the selected alias exposes the Choose Dot shortcut.
- SVG sources and a rendering helper are included. Committed PNG files keep normal Android builds independent of graphics tooling.

Launchers may cache icons or remove an entry when its component changes. Add Talk to Dot again if needed; phone buttons targeting an old icon component may need the app reselected. Android App info and the Accessibility service use the default frog. Navigation speed and behavior are unchanged from v1.2.0.

### Validation

On-device checks passed for the signed update from v1.2.1, unsaved preview behavior, every icon choice resolving to a single launcher entry, saved-name retention, settings access and persistence, signed-update persistence with a non-default icon, and navigation to Zip while the default launcher alias is disabled. A cold ChatGPT restart from Chrome also reached Zip with Cat selected. The exact Tasks → Home → tap the existing Cat icon → Zip flow passed. Niagara preserved the existing home-screen position and displayed the selected Cat artwork. Android registered Choose Dot for the active alias; the tested Niagara long-press menu used its own controls, so the Accessibility settings gear remains the documented fallback. The green frog is restored after checks.
