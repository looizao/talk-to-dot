## Choose your Dot

The shortcut now uses a saved Dot name, with **zip** as the default. Existing installations continue opening Zip until you change the setting.

- Long-press the app icon and select **Choose Dot**, or open the Accessibility service’s settings.
- Save the exact sidebar name, including capitalization. Leading and trailing whitespace is trimmed; blank names are rejected.
- **Save and open Dot** launches the chosen Dot; **Reset to zip** restores the default.
- The Accessibility service uses the saved name for sidebar selection, composer confirmation, and timeout messages. It matches the composer exactly so similar names do not produce a false success.
- The name remains stored locally across restarts and updates. App branding remains Talk to Zip.

The app retains the same signing key and package, allowing an update over the previous release. No new permissions are requested. It still acts only in ChatGPT for 30 seconds after launch and never sends a message or starts a call.

UI labels remain tied to the tested ChatGPT interface; configuring a Dot name does not add translation support. The name must correspond to a Dot you already have in ChatGPT.

### Faster navigation

Fixed waits between different screens are replaced by Accessibility-event handling, with a short watchdog for missed events and throttled retries of unchanged controls. Warm Tasks-to-Zip navigation measured 926 ms versus 2,266 ms before the change on the test phone. The full Tasks → Home → launcher icon flow and ChatGPT restart also passed. A restarted ChatGPT took 8,032 ms to reach the target, so cold startup is still a limitation. Measurements end at accessibility confirmation of the composer, not final animation completion.

### Navigation reliability

Navigation now refreshes nodes and rechecks the active ChatGPT window before interaction. Selecting a Dot waits for its composer instead of immediately reopening the menu from a transitional old-chat screen; a bounded recovery window retries stalled transitions. A short stable-composer check prevents premature success. Navigation stays armed for up to 30 seconds, pauses when another app is foreground, and resumes when ChatGPT returns. Service reconnection preserves an active request.

ADB device checks cover background music, cold startup from Chrome under bounded CPU load, and a switch to Music during startup followed by returning to ChatGPT. `scripts/device-check.py` reproduces these flows; see the README for prerequisites and local snapshot handling.

Final device checks passed with playback active: launch from Music (1,061 ms), cold start from Chrome with two bounded CPU load workers (6,711 ms), and switching to Music during cold startup before returning (4,294 ms, including a two-second interruption). Durations include launch request to composer confirmation and are approximate because ADB UI inspection affects Accessibility delivery. The load workers were stopped and music restored to its previous paused state after testing.

### Configuration validation

On-device checks passed for the default zip, saving and reopening a custom name, blank-name rejection without replacing the saved name, timeout for a nonexistent name without selecting another Dot, resetting to zip across reopening, and Save and open Dot reaching the Zip composer. Zip was restored as the selected name after these checks.
