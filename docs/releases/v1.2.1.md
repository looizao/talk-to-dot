# Talk to Dot v1.2.1

The app and repository are now **Talk to Dot**, reflecting support for any configured Dot name. **zip** remains the default.

- Renames the Android launcher label, setup text, and Accessibility service label to Talk to Dot, with a D icon.
- Moves the repository to [looizao/talk-to-dot](https://github.com/looizao/talk-to-dot) and updates badges, setup instructions, build commands, and release documentation.
- New builds and releases provide `talk-to-dot.apk` with `SHA256SUMS.txt`.
- Preserves the signing key, Android package, Accessibility service component, and saved settings so the signed APK can update existing installations.
- Keeps the navigation behavior and configuration from v1.2.0. Existing v1.1.0 and v1.2.0 APK assets retain their historical filenames.

### Validation

The signed APK is built and verified through the release workflow. On-device validation passed: the signed APK updated the existing installation, Android App info and the bound Accessibility service displayed Talk to Dot, the saved name remained zip, and launching the renamed shortcut reached the exact Zip composer.
